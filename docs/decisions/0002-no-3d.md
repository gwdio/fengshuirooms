# 0002. No 3D in any version

- **Status**: Accepted
- **Date**: 2026-04
- **Revisit**: No

## Context

3D is what makes existing planners heavy. The target user wants "does it fit, where does it go."

## Decision

Top-down 2D only. Height is approximated by three layers (floor / furniture / elevated) and a `tall`
flag for visibility.

## Consequences

Huge scope reduction. Lofted beds and shelves need the elevated layer to feel right.
